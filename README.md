# Data Pipeline & Modelagem Preditiva de Chuvas — Bacia do Rio Fragoso
Repositório de Engenharia de Dados, Modelação Preditiva e Análise Geoespacial em **R** desenvolvido no âmbito do Plano de Trabalho de Iniciação Científica (PIBIC/UPE):  

**"Análise pluviométrica na Bacia Hidrográfica do Rio Fragoso, Pernambuco"** (Subprocesso S04284)

---

## Escopo Tecnológico

O objetivo deste projeto consiste no desenvolvimento de um pipeline analítico reproduzível para consolidar séries temporais pluviométricas históricas, corrigir falhas de monitorização com aprendizagem automática e estimar a distribuição espacial das chuvas na Bacia Hidrográfica do Rio Fragoso.
